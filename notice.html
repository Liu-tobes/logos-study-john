资料与版权说明

本页说明公开演示版所使用的原文、辞书与工具来源，以及公开分享时需要注意的版权事项。

1. 圣经原文与形态

  • SBLGNT（SBL Greek New Testament）：希腊文底本，按 CC BY 4.0 使用。原文版权归 Society of Biblical Literature / Faithlife。
  • MorphGNT / SBLGNT edition：逐词形态标注与词元数据，来源：github.com/morphgnt/sblgnt。
  • Strong's Greek Dictionary（1890，公版）：Strong's 编号参考。
  • STEPBible TBESG：希腊文简明词义，按 CC BY 4.0 使用；中文简释为编者整理。
  • 页面中的形态中文说明与词形码，由 MorphGNT / SBLGNT 标记整理翻译，属于编辑性说明。

2. 中文与旧约文本

  • 和合本（CUV，1919）：中文经文，公版。
  • 马所拉文本（MT）：创世记 1:1、1:3，诗篇 33:6、36:9，以赛亚书 9:2 的希伯来文。
  • 七十士译本（LXX）：互涉卡片中的希腊文旧约引文；诗篇/以赛亚的 MT 与 LXX 编号差异已在页面中标注。
  • 圣经引文均为短句引用，用于研读与对照。
  • 约翰福音全书页（john.html）：中文采用和合本 CUNPS 简体文本；SBLGNT 未收 5:4 与 7:53–8:11（行淫时被拿的妇人段落），这些节次只列和合本并加注，不伪造希腊文。

3. 《圣经新辞典》

公开版内嵌了 16 条与约翰序言相关的《圣经新辞典》词条（道、神、生命、光、创造、人、恩典、真理、见证、荣耀、肉体、道成肉身、会幕、弥赛亚、创世记、话/道）。 这些正文来自用户提供的本地 CHM 解压词条，经清洗、重排后内嵌于 index.html，未上传原书图片与其余 2,332 条内容。

该辞典的版权归原出版方。公开部署前，请确认已获得公开传播授权。若版权方有异议，请删除 index.html 中对应的 <template data-dict-key=...> 块，或改为仅保留短引文与书目信息。

4. 词频与文学分析

  • 词频由 MorphGNT 约翰福音 15,438 个词位统计；母题按词元/词族归并。
  • 交错结构 A–B–C–X–C′–B′–A′ 为建议性阅读模型，不是唯一划分。
  • 中文语义、句法注脚、互涉说明与文学分析为编者整理，不替代专业释经书或校勘本。

5. 运行时与隐私

  • 页面是静态站点（HTML / CSS / JS / JSON 数据），不需要后端；不收集访问数据。
  • 字号、辞典偏好等只保存在浏览器 localStorage。
  • 公开版不读取本地辞典文件夹，也不使用 iframe。
