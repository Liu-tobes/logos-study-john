Reading the Axis

轴心落在 1:2 的 οὗτος（“这一位”）。它把 1:1 的三重陈述收束为一个回指： 那位太初有道、与神同在、就是神者，正是接下来创造与照明的主语。

A · B · C · X · C′ · B′ · A′

Symmetry & Difference

A 以“太初”、A′ 以“光”开显；B 与 B′ 都围绕“同在/在内”；C 与 C′ 则由“道是神”转向“万物借他而成”。 对称不是重复，而是把身份推向作为。

交错结构是读者对重复、轴心与包孕关系的描述，并非约翰明说的图式；学界对本段划分亦有不同方案。此处采用“1:1–5 序言单元”的演示性读法，重点在训练结构观察，而非判定唯一答案。

语法张力与修辞

Grammar as Rhetoric · Tension & Emphasis
从词序、时态与连接词读神学
先读三句话

一：约翰把“神”提到句首，是为了强调“道就是神”，不是“有一位神”。

二：道用“一直在”的动词，万物用“被造成”的动词；时态本身在划创造者与受造界的界线。

三：光一直照着；黑暗的抓取、理解或胜过都没有成功。下面的术语卡只是把这三句话拆开说明。

颜色说明：希腊词下方的彩色小字是“和合本对应译法”。和合本会按上下文调整，所以同一个希腊词可能出现“有 / 同在 / 就是”等不同译法，不是逐字字典式对译。

01 / WORD ORDER

θεὸς ἦν ὁ λόγος

和合本：道就是神
谓语前置
Predicate Fronting

一句话：把“神”放在最前面，是为了让读者先听见“道是神”，而不是先听见“道与神同在”。

θεός→神
谓语 · 无冠词
质性焦点
+
ἦν→就是 / 是
系词 · 未完成时
持续存在
+
ὁ λόγος→道
主语 · 带冠词
定指回指

希腊文把 θεός 放在句首，形成“神—是—道”的强调词序。无冠词的谓语名词在这里更可能是质性用法：道具有神之所以为神的一切所是；它不是把道等同于父，也不是把“神”降格为一个类别。著名的 Colwell/Harner 讨论提醒我们：不应把无冠词机械地译成“一个神”。

02 / ASPECT

ἦν 与 ἐγένετο

和合本：有 / 同在 / 就是 · 造的 / 成了
存在 vs. 生成
Being & Becoming

一句话：道是“一直在”，万物是“被造成”；两个动词的差别，就是创造者与受造界的差别。

ἦν→有 / 同在 / 就是
未完成时 · 持续

1:1–2 连续四次：道“常在”，没有起点叙事。

ἐγένετο→造的 / 成了
不定过去时 · 成为

1:3 两次：受造界“成为”；万物有一个开端。

约翰用两个动词的时态差，划出创造者与受造界的界线：ἦν 是未完成时的持续存在，ἐγένετο 是不定过去时的“成为/发生”。1:3 末尾的完成时 γέγονεν 再把“已经造成”的事实钉牢。

γέγονεν→造的 和合本 1:3
ἐγένετο→成了 和合本 1:14
03 / VERBAL TENSION

φαίνει 与 κατέλαβεν

和合本：照 · 接受
现在时 vs. 不定过去
Present & Aorist

一句话：光“一直在照”；黑暗的抓取是一次决定性的动作，但它没有成功。

φαίνει→照 和合本 1:5
κατέλαβεν→接受 和合本 1:5

1:5 的 φαίνει（现在时）是持续不断的照耀；κατέλαβεν（不定过去时）则像一次决定性的抓取或对抗。光没有停止照耀，黑暗的回应却被叙述为一个已经发生、却未成功的动作。

抓住 / seize 掌握 / grasp 领会 / comprehend 赶上 / overtake 胜过 / overcome

和合本译“黑暗却不接受光”，把重心放在“接纳/领会”；ESV/NRSV 常译“overcome”。原文保留双关：黑暗既未能理解，也未能胜过。翻译不是消除歧义，而是选择让哪一层先发声。

04 / RHYTHM

καί 的连珠节奏

和合本：和 / 与 / 并
Polysyndeton
礼仪性咏叹

一句话：约翰连续用“和”把句子串起来，读起来像礼拜；这不是啰嗦，而是让语言慢下来。

καὶ ὁ λόγος ἦν πρὸς τὸν θεόν, καὶ θεὸς ἦν ὁ λόγος. 1:1 · 三个分句由 καί 串联；1:1–5 共 7 次 καί。和合本常把 καί 译作“和 / 与”。
和合本：道与神同在，道就是神。

重复的连接词制造出一种缓慢、庄重、几乎礼仪性的推进。它不急于解释，而让读者在“和……和……和……”的节拍中，逐步进入道的三重身份。重复在这里不是贫乏，而是让语言承担敬拜的节奏。

05 / INTERTEXTUAL GRAMMAR

ἐν ἀρχῇ：一句被重新打开的创世记

和合本：太初 / 起初
LXX Genesis 1:1
词语复用

一句话：约翰用创世记的第一句话开场，但把“神创造”换成了“道存在”；同一个开头，被放进更深的起点。

七十士译本创世记 1:1 以 Ἐν ἀρχῇ 开始：“起初，神创造……”。约翰没有引用整句，只取这两个词作为序言的第一个音节，却把读者直接带回创造的起点。不同之处在于：创世记接着写“神创造”，约翰接着写“道存在”。同一个开端，被放进一个更深的先在性里。

LXX 创 1:1
Ἐν ἀρχῇ ἐποίησεν ὁ θεὸς τὸν οὐρανὸν καὶ τὴν γῆν. “起初，神创造天地。”
01b / 原文 vs 和合本

语序不同，焦点也不同

和合本不是逐字对照本。它把希腊文的语序、冠词、时态和介词结构，改写成自然中文；差异首先是语言差异，不一定是神学差异。

Greek reads LTR →
Hebrew reads RTL ←
希腊文 从左往右读 → θεὸς ἦν ὁ λόγος
希伯来文 从右往左读 ← בְּרֵאשִׁית בָּרָא אֱלֹהִים
希腊文语序 · 从左往右
θεὸς → ἦν → ὁ λόγος
神（前置谓语）→ 是 → 道（主语）
⇄语序被重排
和合本
道就是神
主题“道”在前，谓语“神”在后

“神—是—道”这种写法有问题吗？它作为逐词顺序的中文速记可以，但必须小心：希腊文里 ὁ λόγος 是主语，θεός 是前置谓语。若把它当作可逆等式，容易读成“父就是道”或“神就是道”的混淆。更准确地说：道（主语）—是—神（谓语）。和合本“道就是神”把中文主题放在前面，并用“就是”标出谓语，是自然的语序调整，不是改教义。

方向不要记反：希腊文从左往右读；希伯来文才从右往左读。把 θεὸς ἦν ὁ λόγος 写成“神—是—道”，只是在搬希腊文的词序，不是说希腊文从右往左。

和合本常见的调整：省略冠词“那/这”、把希腊文的时态转成中文动词、把介词短语移到自然位置、用“就是 / 是……的”补出结构、把分词或关系从句改成短句。下面几行可以直接对照。

原文逐词 / 语序和合本主要差异
Ἐν ἀρχῇ ἦν ὁ λόγος 在起初 是 那 道 太初有道 用“有”表达存在；省略冠词“那”
θεὸς ἦν ὁ λόγος 神（谓语）是 道（主语） 道就是神 希腊谓语前置 → 中文主题化，并补“就是”
πάντα δι’ αὐτοῦ ἐγένετο 万有 借着他 成为 万物是借着他造的 补“是……的”，把“成为”译作“造”
τὸ φῶς ἐν τῇ σκοτίᾳ φαίνει 那光 在 那黑暗 照耀 光照在黑暗里 语序调整；现在时的“持续”未单独标出
ἡ σκοτία αὐτὸ οὐ κατέλαβεν 那黑暗 它 不 抓住 / 胜过 黑暗却不接受光 “接受”是解释性译法；κατέλαβεν 有“抓住/胜过”义

结论：和合本的语序调整是为了让中文读得通、读得顺；希腊文的词序则承担强调和焦点。两者不是谁“更准确”，而是在各自语言里完成同一件事：让读者看见道与神的关系。
